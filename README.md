# Portfolio

Amirul Irfan's personal landing page: a small 3D street in Kuala Lumpur where each shop runs a mini demo of a DaulatLabs system.

It is one static file, `index.html`. three.js (r128) loads from cdnjs. There is no build step.

- Live: https://ipan.daulatlabs.com
- Older versions are in `archive/`.
- To run it locally, open `index.html` in a browser.
